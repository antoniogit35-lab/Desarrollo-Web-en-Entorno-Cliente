# Club de Taekwondo Nonote · Proyecto DWEC UD5

## Contenido

- `parte1/`: formularios y validación sin regex (Tema 5A).
- `parte2/`: ampliación con expresiones regulares (Tema 5B), con `pruebas.js` y `pruebas.md`.
- `memoria.md`: memoria breve.

## Cómo abrir la aplicación

1. Abre la carpeta `parte1` o `parte2` en VS Code.
2. Lanza Live Server sobre `index.html`.
3. Abre la consola del navegador (F12): no debe mostrar errores.

## Cómo ejecutar las pruebas automáticas

En la carpeta `parte2`: `node pruebas.js`. Debe terminar con «Todas las pruebas pasan».

## Requisitos completados

- Cinco formularios: socios, servicios, testimonios, noticias y citas.
- Validación con atributos HTML y JavaScript, mensajes junto al campo con `textContent`, `aria-describedby` y `aria-invalid`, foco en el primer error.
- Confirmación simulada; no se muestra la contraseña ni el archivo.
- Parte 2: reglas de nombre, usuario, contraseña y teléfono; código de servicio; referencia de cita; normalización; extracción de cifras; separación de etiquetas; demostración con `pattern`.
- Pruebas documentadas en `pruebas.md` de cada parte.

Todos los datos usados son ficticios.
